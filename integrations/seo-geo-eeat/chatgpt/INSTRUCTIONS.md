# ChatGPT deployment adapter

These instructions are a wrapper, not a claim that ChatGPT automatically loads files from GitHub.

1. Add the three shared SKILL.md texts to the approved ChatGPT workspace/project or make them reachable through an authorised repository connector.
2. For user requests, start in read-only mode; identify exact node ID, website, culture and approved source corpus.
3. Invoke the optimiser first, governance second; only then offer field-level diff and a draft write.
4. Prefer an approved MCP/API connector enforcing the tool contract at ../mcp-tool-contract.json. If using computer use, require a supervised authorised login and follow the draft-operator restrictions.
5. Never claim to have verified Search Console, AI citations or CMS save state without an actual tool result.
6. Do not forward confidential bank documents to public GitHub; retrieve approved policy references at execution time.
